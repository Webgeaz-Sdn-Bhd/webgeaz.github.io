    SØAD developer guide¶

    Build a complete web application using Jython controllers, SQL-backed models, and HTML views. This guide takes you from your first transaction to a protected project/task tracker deployed in a container.

    You need basic programming, HTML, and SQL knowledge. You do not need to write the Java engine or use AI to follow the tutorial. SØAD, SOAD, and soad refer to the same framework; S0ADM is its development and administration interface.

    What you will build¶

    The tracker example includes projects, tasks, assignment to application users, status filtering, pagination, validation, private attachments, and a JSON endpoint. Members manage their own projects; an administrator permission controls destructive project deletion. Business ownership is checked independently of route permissions.

    The tutorial uses the default application and MySQL, Java 21, and local application authentication. H2 is used for isolated checks. Production deployment contains the application and authentication runtime, without the S0ADM IDE.

    Version and verification¶

    This guide was consolidated against the repository implementation on 2026-09-06. Consult the checked-out Gradle dependencies and soad version when comparing another installation. CLI examples were checked against executable help from commit 5342396 (a development build); installed releases may differ. The example README records reproducible verification commands and limitations.

    No live account, API key, license, database password, or private registry is required merely to read or build this documentation site.
