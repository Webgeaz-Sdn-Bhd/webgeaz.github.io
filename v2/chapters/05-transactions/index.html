    5. Transactions and routing¶

    A transaction is a Jython class loaded by its group and code. For tracker/project.py, the class name is Project. For address_book.py it is Address_book, not AddressBook.

    URL and action contract¶

    Request Controller action
    /t/tracker/project Project.view(ctx)
    /t/tracker/project/edit?id=7 Project.edit(ctx)
    /t/tracker/project/save Project.save(ctx)
    /other/t/tracker/project Other configured application's Project.view(ctx)

    The normal default action is view. The request parameter d_action can select the action too. Give every public action an explicit policy, and prefix internal helpers with _ so they cannot be invoked as routes.

    class Example(object):
    ACCESS_POLICY = {"view": "authenticated", "save": "authenticated"}

    def view(self, ctx):
        ctx.go_to = "/t/web/hello"

    def save(self, ctx):
        """POST"""
        # Validate first, then save and redirect.
        ctx.go_to = ctx.ctxPath + "/t/web/hello"

    def _normalize(self, value):
        return (value or "").strip()

    For mutation actions, the docstring must start exactly with POST, PUT, or DELETE. The engine checks these prefixes for explicitly selected actions. A GET docstring is not a general GET-only guard; keep view read-only. Use POST forms for tutorial writes and deletions.

    Request and response context¶

    API Use
    ctx.getRequest(), ctx.getResponse() Jakarta servlet request/response
    ctx.getParameter("name") Ordinary submitted parameter
    ctx.getHeader("HX-Request") Request header
    ctx.json() Parse JSON body to a map
    ctx.output Values available to the view
    ctx.output["current_user"] Authorized application identity
    ctx.ctxPath Framework routing prefix; preserve it in links
    ctx.go_to Redirect string or response callable
    ctx.page_layout = False Disable wrapper for fragments/JSON/downloads

    render.as_view(ctx, "edit") returns a callable; assign it to ctx.go_to. Returning a value from an action is not the normal response mechanism. ctx.redirect(url) sets the redirect destination.

    Validation and response status¶

    Trim text, enforce lengths, allowlist enumerations, and parse IDs before database access. On invalid input re-render the form with the submitted values and field feedback. HTML validation is convenience; the controller enforces the rules.

    as_view sets status 200 when invoked. To return an HTML form with 400:

    from utils import render

def _invalid_form(ctx):
    render_view = render.as_view(ctx, "edit")
    def response():
        html = render_view()
        ctx.getResponse().setStatus(400)
        return html
    ctx.go_to = response

    For missing private records, return 404 without revealing who owns them. For invalid parameters use 400. A denied permission or invalid CSRF token gives 403; missing security setup gives 503. Always inspect response content and redirects when testing, not just whether a request completed.
