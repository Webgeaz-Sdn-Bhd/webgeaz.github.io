    9. Files, APIs, and integrations¶

    Add integrations after the main CRUD flow and its access rules work.

    Upload and download¶

    Use enctype="multipart/form-data" and a named file input. The framework's request wrapper exposes an UploadedFile through getParameter:

    upload = ctx.getRequest().getParameter("attachment")
if upload:
    filename = upload.getFileName()
    size = upload.getSize()
    content = upload.getBytes()       # only for a deliberately bounded small file

    It also supports getInputStream() and writeTo(destination). The wrapper must be accessed through ctx.getRequest() for files: the convenience ctx.getParameter() has a Java String return type and cannot return UploadedFile. The wrapper provides <field>_fn and <field>_ft metadata. Empty uploads are falsey. Do not call multipart parsing again inside the controller. Temporary files are cleaned when request processing finishes; copy or consume them during the action.

    Configure max.file.upload.size, max.request.upload.size, and optionally file.upload.temp.dir. Oversized requests return 413. The tracker adds a 1 MiB application limit and sanitizes the download filename; it never uses the submitted name as a filesystem path.

    The tracker reads an attachment only after checking project ownership and the task's project membership. It sets attachment=True, an opaque content type, and X-Content-Type-Options: nosniff. It does not scan malware or make uploaded content safe to execute. Add scanning/quarantine if your application's use requires it.

    For large files use bounded streaming and private storage with generated keys. If a filesystem write accompanies a database update, define cleanup/retry behavior explicitly: database rollback does not remove the file.

    JSON and AJAX¶

    ctx.page_layout = False
ctx.go_to = render.as_json(ctx, {"ok": True, "project_id": project.getId()})

    Pass a deliberately selected object. Calling as_json(ctx) without one serializes all output, which may include identity and CSRF context unsuitable for the endpoint. Never serialize whole auth models.

    Use ctx.json() for request JSON and validate keys/types before updates. Cookie-authenticated AJAX must carry cookies and the CSRF-Token header on protected writes. A login redirect is not a JSON success response; clients should detect expired authentication and navigate to sign-in.

    The framework does not infer CORS, bearer authentication, or an API versioning scheme from a JSON response. Design those requirements explicitly with filters and/or a custom provider.

    Email¶

    The bundled mail utility is from utils import mailer. Its concrete entrypoints are listed in rendering and utilities. Set mail configuration through environment variables and restart after changes; the utility establishes configuration at module load.

    Use a test relay before enabling account recovery in production. Confirm sender identity, public HTTPS links, and delivery with your mail operator. The current bundled SMTP helper explicitly trusts all TLS certificates on its STARTTLS path. It should not be described as certificate-verified transport; use a controlled relay/network boundary or remediate the mail transport before relying on it across an untrusted network.

    Do not send email inside a request and assume database rollback can recall it. For reliable notifications, persist an outbox entry in the transaction and have an external worker deliver/retry it. SØAD does not automatically provision that worker.

    Reports and external services¶

    render.as_pdf renders a Handlebars view through the bundled PDF converter. Use a report-specific, simple HTML/CSS template rather than expecting browser JavaScript or a full Tailwind layout to print identically.

    Apache POI can generate Excel workbooks. Use server-generated filenames and the file/blob renderers for downloads. Escape spreadsheet formula-leading user text when exporting untrusted strings.

    Java's HTTP client can call external services from Jython. Set connection/request timeouts, validate response status, keep keys in environment-backed configuration, and decide whether failure should abort the business update or be retried later. CPython libraries such as requests are not part of this runtime.
