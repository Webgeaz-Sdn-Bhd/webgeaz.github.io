    Configuration reference¶

    Properties are loaded from SUFIA_HOME/conf/sufia.properties; environment variables overlay them. The normal mapping replaces underscores with dots: db_default_driver_class becomes db.default.driver.class. Use the documented spelling rather than inventing an alias.

    The development profile is app/conf/sufia.properties; application-only images copy app/conf/sufia-runtime.properties into that runtime location. Do not copy environment-specific values from the development profile into docs or releases. Restart for configuration changes unless a feature explicitly documents live updates.

    Application and database¶

    Property Environment Meaning
    sufia.home SUFIA_HOME Runtime root; special startup variable
    sufia.mode sufia_mode development reloads transaction modules; production for deployments
    sufia.context_path sufia_context_path Servlet context; special compatibility handling
    sufia.app.name sufia_app_name Application display name for runtime pages/email
    sufia.hostname sufia_hostname Public origin used for generated links
    sufia.welcome.transaction sufia_welcome_transaction Operator override for root welcome transaction
    db.default.url db_default_url JDBC URL for default app
    db.default.driver.class db_default_driver_class JDBC driver, e.g. com.mysql.cj.jdbc.Driver
    db.default.username db_default_username Database account
    db.default.password db_default_password Database password, injected as a secret

    The driver reader also accepts legacy driverclass/driver_class spellings, but examples use driver.class. Each configured datasource name is also an application name. Do not assume the single-app local-auth manifest architecture provides arbitrary multi-tenant security automatically.

    Welcome resolution is the operator property first, then the released WEB-INF/sufia-app.properties, then the framework fallback. An explicit blank operator value selects the existing static index instead of a transaction.

    Sessions and uploads¶

    Property Shipped production value / behavior
    session.cookie.httponly true
    session.cookie.secure true; use HTTPS
    session.cookie.samesite NONE; tracker examples override to LAX
    session.timeout 1800 seconds servlet idle timeout
    max.file.upload.size Maximum individual upload bytes; legacy maxfileuploadsize takes precedence if set
    max.request.upload.size Aggregate request bytes; legacy maxrequestuploadsize takes precedence
    file.upload.temp.dir Upload spool directory; otherwise JVM tmp/soad-uploads

    Environment forms include session_cookie_secure, session_cookie_samesite, session_timeout, and max_file_upload_size. Check whether a legacy upload property is already set before adding a dotted replacement. Application auth records have their own expiry and revocation checks. Jetty's file session store uses JVM tmp/s0-session-store.

    Email and AI¶

    SMTP: mail.smtp.host, mail.smtp.port, mail.smtp.username, mail.smtp.password, mail.sender.email. The corresponding variables replace dots with underscores. Read the current TLS limitation in the integration chapter.

    AI: ai.enabled, ai.provider, ai.endpoint, ai.api.key, ai.model, ai.auto.accept. IDE-saved fields take precedence over properties/environment. ai.one.shot.auto.security defaults true; turning it off changes inference, not explicit requests for protected access.

    For generation limits inspect app/s0adm/ai/config.py for ai.turn.cap, ai.one.shot.turn.cap, ai.context.max.tokens, and ai.max.output.tokens; tune against the selected provider's actual limits. These are development/IDE settings, not runtime application requirements.

    Advanced runtime mappings¶

    Servlet/filter mappings are configured as servlet.<name>.mapping/file and filter.<name>.mapping/file. Ordinary application transactions need no per-route configuration. Static mappings use static.<name>.mapping/dir. Context listeners use the configured listener mechanism.

    Error overrides use error.page.<status> and error.page_exception; see error pages. The development-only manifest exemption setting sufia.security.manifest.exempt_apps exists for the IDE; do not exempt your protected application to silence a setup error.
