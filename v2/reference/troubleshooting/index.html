    Troubleshooting and glossary¶

    Diagnosis table¶

    Symptom Explanation / next check
    Model import fails Table missing, wrong datasource, or models not refreshed
    Attribute/method missing in Jython Check Python 2.7 syntax and actual Java method signature
    Saving does nothing Assign ctx.go_to; inspect errors; manual string IDs need insert on first save
    Login loop App account vs IDE account; HTTPS and Secure/SameSite cookie settings
    403 for every user Missing ACCESS_POLICY, unregistered permission, no role grants, or CSRF
    503 on protected route Manifest missing/invalid or installed auth checksum differs
    Unexpected 404 Wrong class capitalization, route, failed import, or ownership intentionally hidden
    413 on upload Per-file or aggregate request limit
    JSON appears inside HTML Disable page_layout for that endpoint
    Styles missing after deployment Public assets absent, wrong ctxPath, or dependence on IDE-only assets
    Auth customization ignored Validator rejection, wrong directory, missing form/context requirements
    New filter is not active Restart; filter discovery is cached
    AI feature missing Master switch, provider settings, IDE privileges/image/migrations
    AI changes applied without a click Check auto-accept and whole-app generation mode
    Release build unavailable Kaniko missing from the development image
    Auth health green but page fails Health checks auth metadata, not all business tables
    Docs diagram shown as text Mermaid support/JavaScript blocked; inspect hosted site and CSP

    Avoid logging secrets while investigating. Reproduce one request, inspect its actual status, body, redirects, and relevant log excerpt, then verify database state if it was a mutation.

    Glossary¶

    Term Meaning
    Transaction A group/code Jython controller and its views
    Action A routed public method, normally view/save/edit
    Database transaction Commit/rollback boundary around request work
    WebContext / ctx Request/response bridge and template output map
    Model Generated ActiveJDBC class for a database table/view
    Introspect Regenerate model metadata/classes from database schema
    S0ADM Browser IDE and development control plane
    Runtime Application-serving process/container
    Security profile Public, authenticated, or mixed application classification
    Auth mode Local, custom, or public identity implementation
    ACCESS_POLICY Controller mapping from action names to access requirements
    Permission Registered capability granted through roles
    Ownership Business rule restricting which records a user may access
    Manifest Versioned application security metadata with checksum
    Release Source/image artifact; not a database backup
    Skill Instructions/reference bundle loaded by a compatible coding agent
