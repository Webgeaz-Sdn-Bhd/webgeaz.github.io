    Rendering and utility reference¶

    Import from utils import render. Most rendering functions return a callable: assign it to ctx.go_to. Set ctx.page_layout=False for non-page responses.

    Renderers¶

    Call Result / important parameters
    as_view(ctx, view, group=None, code=None, loc=None, file=None, combine_map=None) Handlebars HTML; view name omits .html; sets status 200
    as_string_template(ctx, view) Inline Handlebars string rendered from output
    as_json(ctx, obj=None, status=200) JSON; omitted obj serializes all output
    as_html(ctx, code=None, loc=None) Reads raw HTML without template expansion
    as_string(ctx, text_string, status=200) Literal HTML string, not escaped text
    as_file(ctx, file, content_type, filename=None, attachment=True) Streams a filesystem path or java.io.File
    as_blob(ctx, content, content_type, filename, attachment=False) Streams byte content
    as_pdf(ctx, view, group=None, code=None, file=None, filename=None, combine_map=None, attachment=False) Converts a Handlebars document to PDF

    Examples:

    ctx.go_to = render.as_view(ctx, "edit")
ctx.go_to = render.as_view(ctx, "summary", group="reports", code="monthly")
ctx.go_to = render.as_json(ctx, {"ok": True}, status=201)
ctx.go_to = render.as_blob(ctx, data, "application/octet-stream",
                          "report.bin", attachment=True)

    These lines are alternatives; only the last assigned response is used. Some JDBC drivers return a java.sql.Blob rather than bytes. For deliberately bounded blobs, call blob.getBytes(1, int(blob.length())) before as_blob; its input must support byte-array operations. Stream large values separately. Avoid loc/file unless intentionally resolving a framework-specific alternate view location. Never let a submitted path select an arbitrary template/download. as_string is HTML, so use constant text or explicit escaping for user values.

    Template helpers¶

    Helper Example / purpose
    eq, neq, gt, gte, lt, lte {{#eq status "done"}}Complete{{/eq}}
    and, or, not Conditional composition
    length, size {{length projects}} for collections
    dateFmt {{dateFmt created_date "yyyy-MM-dd"}}
    html Escape text, preserve newlines, linkify URLs
    select, option Build select markup/options from supplied refs or a model table
    ref_lookup Resolve a display label by model table or supplied refs
    session Read a named session attribute; do not expose secrets
    get Resolve an output key as safe content; use only trusted values
    i18n Resolve resource-bundle labels

    The normal view renderer also registers Handlebars string helpers. Model-backed select/ref helpers can perform database queries. Prefer prefiltered refs for private data so the helper cannot accidentally show a global table:

    {{select name="assignee_id" refs=people label="full_name" value="id" selected=task.assignee_id}}

    Do not put untrusted SQL in a helper's filter attribute. For reusable views, prepare lookup lists in the controller to avoid per-row queries.

    Email and Java libraries¶

    The SMTP entrypoint is:

    from utils import mailer
mailer.send(None, "recipient@example.com", "Project update",
            "Your project was updated.", html=False)

    Its full signature is send(fr, to, subject, content, cc=[], bcc=[], html=False, attachment=[], inline=[], reply_to=None). Use actual configured recipients and reviewed templates. send_api is a separate provider-specific path; inspect its configured API integration before adopting it. See email deployment constraints.

    Bundled libraries include Java time/IO, Google Guava, Apache Commons, Apache POI, Jakarta Mail, and the PDF converter. The authoritative versions are in sufiao-core/build.gradle; do not infer that any arbitrary Java JAR is already bundled.

    Log through from sufia.util import Log and Log.info(ctx, message). Use utils.fileupload.UploadedFile for multipart file handling rather than calling a second upload parser.
